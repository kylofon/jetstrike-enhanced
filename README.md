# JetStrike — SDL3 port

A faithful C reimplementation of *JetStrike* (1994, Shadow Software / Rasputin, DOS CD-ROM edition),
running natively on SDL3. It is not an emulator: the original program is being reverse-engineered,
documented and rewritten in C, and the port reads the original game's files at run time. The original
data is not redistributed.

Status: reverse engineering has started. See [PLAN.md](PLAN.md).

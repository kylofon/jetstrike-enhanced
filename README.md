# JetStrike Enhanced

*JetStrike* (1994, Shadow Software / Rasputin, DOS CD-ROM edition) on SDL3 with a larger playfield: the
original pixels at 1:1, but a 640×360 view instead of 320×240, so more of the map is visible. Built on the
faithful port [jetstrike-sdl3](https://github.com/kylofon/jetstrike-sdl3) (history merged in as `upstream`).
The port reads the original game's files at run time; the original data is not redistributed.

Status: planning. See [PLAN.md](PLAN.md) (Enhanced) and [PORT_PLAN.md](PORT_PLAN.md) (the faithful port).
